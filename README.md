# Bangtao Conditioning

A mobile first 7 week conditioning and durability tracker for preparing for Muay Thai training at Bangtao.

## Features

- 7 week progression
- Adjustable kickboxing schedule
- Plantar pain based training adjustment
- Plantar fascia rehab checklist
- Strength and durability sessions
- Zone 2 cycling
- 3 minute fight intervals
- Shadowboxing progression
- Embedded YouTube exercise tutorials
- Local browser storage for daily history
- Mobile Safari friendly

## GitHub Pages

Publish from the `main` branch and repository root in Settings > Pages.

Workout data is stored in the browser using localStorage. It does not sync between devices.
